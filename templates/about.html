About This Project

This project analyses Olympic performance from 1992 to 2026 for 60 countries and 50 sports, using Tableau dashboards and a story embedded in a Flask web application.

Priya: Performance Strategist

Which sport categories give the best medal return per athlete, and how does her country compare with the top nations?

Carlos: Investment Analyst

Which countries and regions turn sports investment into medals most efficiently?

William: Data Journalist

How have medal totals changed over time, and do host nations win more at home?

Tools and method

  • Tableau Public: data connection, 4 calculated fields, charts, 2 dashboards and a story
  • Flask (Python): web application with Home, About, Insights, Dashboard and Story pages
  • Tableau JavaScript Embedding API: interactive embedding of the published views
  • Bootstrap 5: responsive layout
